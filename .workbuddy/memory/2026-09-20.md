## 踩坑
- Node fetch 请求 `localhost` 会优先解析 ::1 → ECONNREFUSED（服务只听 IPv4）。脚本内已把 base 的 localhost 改写成 127.0.0.1。
- Bash 前台命令结束后子进程会被杀，探测服务要用 `run_in_background` 启动，否则 node fetch 全 ECONNREFUSED 而 curl 正常。
- 4xx/5xx 响应体是 axios 错误对象（含随机字段），结构指纹会误报差异 → status≥400 时指纹降噪为 `ERR:<status>`。
- 静态启发式判断"需登录"不准（/album/sub、/calendar、/msg/* 等 36 条实际返回 301）→ 用实测 `--write-back` 校正分层，别信静态推断。

## Fastify 迁移踩坑
- `@fastify/compress` 的 onSend 会把 payload 变成流 → 缓存写进空串 → 命中返回 0 字节。默认关闭压缩（`ENABLE_COMPRESS=1` 开启），且 onSend 只缓存 `typeof payload === 'string'`。
- Node fetch/undici 不自动解压 brotli → compress 只允许 gzip。
- util/qq.js、util/kugou.js 是 `{ success(fn) }` 回调风格 → 必须包 Promise，否则 async handler 提前结束，Fastify 回空 200。
- Fastify 默认 404 是 JSON，与 Express 的 HTML `Cannot GET /x` 不同 → 用 setNotFoundHandler 复刻。
- TS 里 `require('crypto')` 被解析成 globalThis.crypto（webcrypto，无 createHash）→ 用 `require('node:crypto')`。
- 随机内容接口（/personal_fm）指纹会误报 → 用例加 `looseSignature: true`，只比顶层结构。
